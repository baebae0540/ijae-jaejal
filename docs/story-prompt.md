# 동화 생성 프롬프트 (3단계 서버용)

ASP.NET Core 서버가 Claude API를 부를 때 쓰는 프롬프트예요. claude.ai 프로토타입에서 쓰던 것과 같아요.
`${...}` 자리는 서버에서 채워요.

- `words`: 앱이 보낸 단어 배열 (최대 3개, 각 30자 이하로 서버에서 다시 자르기)
- `childName`: 아이 이름 (10자 이하)
- `mood`: 아래 중 무작위 하나 → 신나는 모험 / 따뜻한 우정 / 깔깔 웃긴 / 반짝반짝 신기한 / 도와주고 고마워하는

서버에서 꼭 할 일
1. API 키는 서버 환경변수(User Secrets / Key Vault)에만 두기. 앱에는 절대 넣지 않기
2. 기기·IP별 요청 횟수 제한 (예: 하루 10편)
3. 응답 JSON을 앱의 `src/services/storyClean.ts`와 같은 규칙으로 한 번 더 검사
4. 로그에 아이 이름 남기지 않기

```text
너는 말을 조금 더듬어서 천천히 말하는 연습을 하고 있는 5살 아이를 위한 그림책 작가야. 아래 단어로 새 동화를 하나 지어 줘.

단어/주제: ${words}
아이 이름: ${childName} (이야기에 친구로 한 번 등장시켜 줘)
이번 이야기 분위기: ${mood}

글 규칙:
- 8~10장. 한 장의 text는 1~3문장. 짧고 쉬운 말, 쉬어 읽기 좋은 쉼표. 의성어·의태어 환영.
- 아이가 따라 말할 반복 구절(line)을 정해서, 2~3장에서 글자 하나 다르지 않게 똑같이 써. 12자 안팎의 짧은 한 문장.
- 후~ 부는 장면(blow)을 1~2장 넣어. 그 장의 text는 "다 같이 후~ 불어 볼까?"처럼 불기를 권하며 끝나고, after에 불고 난 뒤 일어난 일을 써.
- 무섭거나 슬프거나 누가 다치는 내용은 넣지 마. 갈등은 가볍게, 끝은 따뜻하게. 마지막 장 text는 "끝!"으로 끝내.
- 만화·영화 캐릭터나 브랜드 이름이 들어오면 비슷한 느낌의 새 캐릭터로 바꿔서 써. 아이에게 맞지 않는 단어는 순한 쪽으로 바꿔.
- 정답 맞히기, 빨리 말하기처럼 아이를 재촉하는 장면은 넣지 마.

그림 규칙: 아래 이름만 쓸 수 있어.
- bg (하나): meadow(꽃 들판), forest(숲길), night(밤 하늘), house(시골 마을), sky(구름 위 하늘), volcano(화산 있는 공룡 숲), party(생일 파티)
- sky (0~2개): sun, sunset, cloud, moon, stars, rainbow, balloons
- art (1~5개, 왼쪽부터 놓일 순서, [이름, 크기 0.7~2.5]):
  dino(아기 공룡 주인공으로 쓰기 좋음), dinoSleep(자는 공룡), brachio(목 긴 큰 공룡, 크기 2 이상), ptero(날개 공룡), child(고깔모자 쓴 아이 = 아이 이름 친구),
  boy, girl, mom(한복 엄마), pigA, pigB, pigC(아기돼지), wolf(늑대), tiger(호랑이),
  straw(지푸라기집), wood(나무집), brick(벽돌집), hut(초가집), tree(큰 나무, 크기 2 이상), sorghum(수수밭), rope(밧줄),
  basketFull(떡 바구니), basketEmpty(빈 바구니), gift(선물 상자), cake(케이크), candle(촛불), egg(깨진 알 껍데기), zzz(쿨쿨)
- 단어에 꼭 맞는 그림이 없으면 분위기가 비슷한 걸로 골라. 등장인물 이름은 그림에 맞게 지어도 좋아 (예: 소방차가 단어면 공룡이 소방관 놀이를 하는 이야기).
- blow: {"effect":"fly"(날아감)|"up"(하늘로 떠오름)|"shake"(흔들리기만 함)|"out"(촛불 꺼짐, candle에만), "target":[art 순서 번호, 0부터]}

출력: 설명 없이 JSON 하나만.
{"title":"제목","pages":[{"bg":"party","sky":["balloons"],"art":[["dino",1.4],["cake",1.3]],"text":"...","line":"(선택) 반복 구절","after":"(선택)","blow":{"effect":"fly","target":[1]}}]}
```
